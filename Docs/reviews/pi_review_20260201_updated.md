## Executive Summary: 关键发现颠覆了原有假设

Partner 的分析揭示了**三个颠覆性发现**，这些发现根本性地改变了我们对 Turkey 2023 数据的理解：

| 原假设 | 实际发现 | 影响程度 |
|--------|----------|----------|
| 50-100km 恢复最快 (τ最小) | **25-50km 恢复最快** (median τ = 1105h vs 1360h) | ⚠️ 颠覆核心结论 |
| τ(r) 存在内部最小值 r* | **Turkey 无 r*** (二次项 c < 0，抛物线开口向下) | ⚠️ 物理解释需重构 |
| "三相分离" (+−+) 是普适现象 | **仅 Turkey 存在**，其他 3 个灾难均无 | ⚠️ 普适性存疑 |

**结论**: 原有的"50-100km 最优恢复距离"假说是**分箱人为产物**。真正的物理图像需要重新构建。

## 1. 连续 τ(r) 拟合：无内部最小值

### 1.1 Turkey 2023 结果

| 参数 | 值 | 含义 |
|------|-----|------|
| 模型 | log τ = a + b·log r + c·(log r)² | 二次对数拟合 |
| n_tiles | 17,572 | 充足样本 |
| a | 4.60 | 截距 |
| b | 0.92 | 正：τ 随距离增加 |
| **c** | **-0.059** | **负值 → 抛物线开口向下** |
| r* | **NaN** | **无内部极值点** |

**物理解释**:

c < 0 意味着 log τ 是 log r 的**开口向下抛物线**。这意味着：
- τ(r) 在定义域内**单调递增后趋于平缓**
- 不存在"最优恢复距离" r*
- **近震中区域恢复最快**，远离震中则恢复变慢

这与我们之前基于 band-level 分析得出的"50-100km 恢复最快"**完全相反**。

### 1.2 跨灾难对比

| 灾难 | 类型 | c 值 | r* (km) | Bootstrap CI |
|------|------|------|---------|--------------|
| **Turkey 2023** | 地震 | -0.059 | **NaN** | - |
| Hurricane Beryl | 飓风 | +0.169 | 342 | [189, 120499] ⚠️ 巨大不确定性 |
| Moldova Flooding | 洪水 | +0.064 | 25 | [0.9, 41] |
| Park Fire | 野火 | +0.029 | 53 | [0.5, 101] |

**关键洞察**:
- 只有 Turkey (地震) 显示 c < 0，其他灾难 c > 0
- 其他灾难存在 r* 但置信区间极宽
- **地震的空间动力学可能与其他灾难类型本质不同**

## 2. Binning 敏感性分析：彻底否定原假设

### 2.1 Winner-mid 分布

对 200 个 jittered binning schemes 进行分析：

| 距离区间 | Winner 次数 | 百分比 |
|----------|-------------|--------|
| **0-25 km** | **171** | **85.5%** |
| 25-50 km | 29 | 14.5% |
| 50-100 km | 0 | **0%** |
| 100-200 km | 0 | 0% |
| 200+ km | 0 | 0% |

**结论**: 
- **85.5% 的分箱方案显示最近距离带恢复最快**
- **原假设 "50-100km 恢复最快" 在 0% 的分箱方案中成立**
- 这是对原结论的**彻底否定**

### 2.2 为什么原分析得出错误结论？

回顾原分析使用的固定边界 [0, 25, 50, 100, 200, 500]km：

1. **0-25km 带**: 样本量小 (n≈340 tiles)，易受极端值影响
2. **人口增长效应**: 0-25km 带显示 φ > 1（人口净流入），不符合"恢复"的传统定义
3. **概念混淆**: 我们测量的是 φ(t) 向稳态的弛豫速率，而 0-25km 可能有不同的稳态

**真正的物理图像**:

```
距离 r →
     0-25km: φ > 1 (人口流入，救援/安置)，且变化速率最快
     25-50km: φ 快速恢复向 1
     50-100km: φ 恢复较慢
     100-200km: φ 恢复更慢
     200km+: φ ≈ 1 (几乎不受影响)
```

## 3. 非参数统计检验

### 3.1 τ 排序显著性

| 比较对 | median_a | median_b | diff | p-value (one-sided) |
|--------|----------|----------|------|---------------------|
| 25-50 vs 50-100 | **1105h** | **1360h** | **-255h** | **0.999** |
| 50-100 vs 100-200 | 1360h | 1283h | +77h | 0.112 |

**解读**:
- p = 0.999 表示 **25-50km 显著快于 50-100km** (原假设方向错误)
- 50-100 vs 100-200 无显著差异

### 3.2 可见性 vs 强度恢复

| 距离带 | median_d (hours) | 95% CI | p-value |
|--------|------------------|--------|---------|
| 25-50km | 48h | [24, 72] | 0.0002 |
| 50-100km | 24h | [0, 24] | 0.0002 |
| 100-200km | 0h | - | 1.0 |

**解读**:
- d = t_intensity ≥ 0.95 - t_first_overlap（强度恢复时间 - 可见性恢复时间）
- 25-50km 的 d 最大（48h），说明该区域"可见性恢复快但强度恢复慢"
- 支持 **假说 B (通达性/accessibility)** 而非假说 A/C (破坏强度)

## 4. 多数据源验证

### 4.1 Movement 数据

| 方向 | 25-50km τ | 50-100km τ | 哪个更快？ |
|------|-----------|------------|------------|
| Inflow | 935h | 885h | 50-100 略快 |
| Outflow | 923h | 968h | 25-50 略快 |

**解读**: Movement 数据显示两区间 τ 差异不大（~50h），不支持任何一方"显著更快"的结论。R² 普遍较低（0.24-0.35），拟合质量存疑。

### 4.2 Network Coverage

| 距离带 | 震后 8h outage_mean | 震后 80h outage_mean |
|--------|---------------------|----------------------|
| 0-25km | 0.327 | 0.158 |
| 25-50km | 0.270 | 0.089 |
| 50-100km | 0.266 | 0.167 |

**关键发现**: 
- 50-100km 的网络中断率 (outage) 在震后持续较高
- 这**支持假说 B**: 50-100km 区域的"慢恢复"可能与通信/交通受阻有关

### 4.3 Business Activity

| 距离带 | τ (hours) | R² | fit_ok |
|--------|-----------|-----|--------|
| 0-25km | 1355h | 0.21 | ✓ |
| 25-50km | - | - | ✗ (拟合失败) |
| 50-100km | 2138h | 0.10 | ✓ (R²极低) |

**解读**: Business activity 数据质量差（R² < 0.2），25-50km 甚至无法拟合。不应作为主要证据。

## 5. "三相分离" 普适性检验

### 5.1 定义
三相分离 (+−+)：从震中向外，人口变化率呈现 增加-减少-增加 的空间模式。

### 5.2 跨灾难结果

| 灾难 | 三相分离存在？ | 首次出现时间 | 模式演化 |
|------|---------------|-------------|----------|
| **Turkey 2023** | **✓ True** | **t=160h** | `+---0` → `+-+-0` → `+-+0+` → `+++++` |
| Hurricane Beryl | ✗ False | - | `?+0--` → `?0000` |
| Moldova Flooding | ✗ False | - | `0000?` → `0+00?` |
| Park Fire | ✗ False | - | `00000` → `+0+++` |

**结论**:
- 三相分离 **不是普适现象**
- 仅在大规模地震 (Turkey 2023) 中观察到
- 可能与地震的**空间衰减特性**有关（intensity ∝ r^{-α}）

## 7. 核心问题诊断

### 7.1 为什么原 band-level 分析误导了我们？

1. **Simpson's Paradox 的变体**:
   - Band-level 聚合的 median(τ) 掩盖了 tile-level 的真实分布
   - 25-50km 带的 median τ = 1105h 被 50-100km 的聚合效应扭曲

2. **固定边界的任意性**:
   - [25, 50, 100, 200]km 完全是人为设定
   - Jittered binning 揭示了真实规律：**最近距离恢复最快**

3. **概念混淆: "恢复" vs "稳态变化"**:
   - 0-25km: φ > 1 (人口净流入) → 这不是"恢复"，是状态改变
   - 我们测量的 τ 对于 φ > 1 区域的物理含义不同

### 7.2 数据质量问题

| 问题 | 证据 | 影响 |
|------|------|------|
| τ 拟合 R² 低 | 很多 tile R² < 0.2 | τ 估计不可靠 |
| Movement τ R² 低 | 全部 < 0.35 | 弱证据 |
| Business Activity 拟合失败 | 25-50km fit_ok=0 | 不可用 |
| Network Coverage 无 τ | 仅有 outage 快照 | 只能定性支持 |

### 8.1 当前状态评估

| 普适性证据 | ⚠️ 仅 Turkey 有三相分离 | 弱 |

### 8.2 两条可能的前进路径

#### 路径 A: 重新定义科学问题

放弃"50-100km 最优恢复"的故事线，转向：

> **"灾后人口恢复的空间梯度：近震中恢复最快的物理机制"**

核心论点：
1. τ(r) 单调递增（近处恢复快）
2. 物理机制：救援资源集中 + 基础设施优先恢复
3. 三相分离是中间态，最终收敛

**优点**: 与数据一致  
**缺点**: 不够"新奇"，可能难发 Nature Comms

#### 路径 B: 聚焦"三相分离"的动力学

> **"地震后人口重分布的时空相分离：从 (+−+) 到均匀化的动力学"**

核心论点：
1. t ∈ [88h, 160h]: 出现三相分离 (+−+)
2. t > 832h: 收敛为均匀 (+)
3. 这是**非平衡相变**的特征（类似 spinodal decomposition）
4. 其他灾难类型不出现 → 地震特异性

**优点**: 有明确的物理类比，Turkey 独特性可以是卖点  
**缺点**: n=1 的事件，普适性论证困难

#### 路径 C: 方法论贡献 + 负面结果

> **"灾害人口动力学分析中的分箱陷阱：来自土耳其地震的教训"**

核心论点：
1. 初步 band-level 分析显示"50-100km 恢复最快"
2. 200 种分箱方案敏感性检验后，结论被推翻
3. 连续 τ(r) 拟合揭示真实规律
4. 这是对灾害研究方法论的重要警示

**优点**: 诚实、有方法论价值、可复现  
**缺点**: "负面结果"通常难发高影响期刊
